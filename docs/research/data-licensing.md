# Data and media licensing checklist

Checked 2026-10-08. This is an operational rights register, not legal advice. A public page or download button does not itself grant reuse rights. Confirm the live terms immediately before acquisition and before release.

| Source | Known/likely rights position | Required action before use |
|---|---|---|
| WWF Living Planet Report 2026 | Report, artwork, tables, and data rights not verified for this edition. | Inspect report-specific copyright, figure/table credits, and supplementary dataset terms. Request permission when reuse is not explicitly licensed. |
| LPI published results | Published index results may be reusable under terms stated by LPI policy; confirm current policy and required share-alike/credit conditions. | Save policy and version. Attribute ZSL/WWF and source studies. Check policy before commercial, modified, or redistributed use. |
| Living Planet Database | Underlying records are not interchangeable with published index outputs. Portal requires use description and acceptance of agreement; confidential records are excluded from public version. | Obtain data directly through portal; archive agreement, purpose, version, and restrictions. Do not redistribute without explicit permission. |
| IUCN Red List API | API terms apply; official API documentation explicitly forbids commercial use and directs commercial users to IBAT. | Do not use in a commercial project absent suitable license/authorization. Request token only after confirming intended use is eligible. Cite actual Red List version and assessment. |
| GBIF | Record/dataset licenses vary (e.g. CC0, CC BY, CC BY-NC). | Preserve GBIF download DOI/citation and per-record licenses; exclude NC data from commercial use unless separately licensed. Cite dataset contributors. |
| OWID | OWID-produced content generally CC BY; third-party materials/data retain original terms. | Attribute OWID authors and link; inspect the chart's source and data license. Do not assume OWID hosting converts third-party data to CC BY. |
| NOAA Fisheries | Federal government material may be public domain, but pages can contain partner/copyrighted media. | Read each dataset/asset notice and assessment citation. Treat recordings and photos as individually rights-managed until verified. |
| BirdLife International | Data Zone bulk data may be proprietary, permissioned, or fee-based. | Check current product terms; obtain written permission/license for extraction, adaptation, or redistribution. |
| xeno-canto | Recording-level licenses vary; NC/ND/SA conditions can apply. | Store record ID, recordist, exact license URL, attribution text, and any modification. Use only assets whose exact terms fit intended distribution. |
| Macaulay Library | Rights and reuse permissions vary by item/creator; access is not a reuse license. | Request explicit permission for each selected recording/image/video and follow credit instructions. |
| Wikimedia Commons | File-by-file free licenses/public domain; Commons disclaims warranty of rights metadata. | Verify file page, author, source, license, attribution, modifications, share-alike, and non-copyright rights. |
| iNaturalist | Observation and each media item may have distinct contributor-selected licenses; NC content cannot be used commercially. | Check asset-level license and creator, not just observation license. Follow API terms and credit requirements. |
| USFWS media | Some U.S. government-created files are public domain; third-party content can be present. | Verify item-level rights note, photographer/agency credit, and any likeness/privacy restrictions. |
| NPS Natural Sounds gallery / Yellowstone Sound Library | Both official library pages explicitly identify their linked sound files as public domain, permit downloading/reuse, and request appropriate National Park Service credit. | Six item-page recordings were acquired on 2026-10-09. See [audio receipt and processing ledger](../../data/sources/audio-assets.json) and [soundscape method](../development/soundscapes.md). Do not extend this clearance to outside or third-party audio libraries. |

## Per-asset license record

Before adding a data record or media asset to the project, record: stable source URL/ID; publisher and creator; retrieval date; source/version; exact license name and URL; attribution text; commercial permission status; derivative/share-alike/NC/ND conditions; whether redistribution is allowed; and any separate privacy, trademark, or sensitive-species restrictions. Keep a local copy only when permitted.

For scientific statistics, record both the dataset license and the citation requested by the originating publisher. Citation is not a substitute for permission.
