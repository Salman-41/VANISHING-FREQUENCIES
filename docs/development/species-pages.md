# Species Explorer and species records

Implemented 2026-10-09. The routes consume only the validated `data/processed/biodiversity.json` export through the existing server-only loader and matching validation report. The research foundation, measurements, scientific dates, citations, and acquired media bytes are unchanged. No restricted IUCN data, population reconstruction, occurrence-derived abundance, new backend, or external playback was introduced.

## Explorer behavior and data basis

`/species` is rendered on the local server at request time so the GET form and query links work without JavaScript. The six detail pages remain statically generated by `generateStaticParams`; unknown slugs cannot create a substitute species record. The collection stays in its established documentary order by default.

| URL key | Accepted values / behavior | Data basis |
| --- | --- | --- |
| `q` | Literal common/scientific-name substring; case-insensitive, surrounding whitespace ignored | `commonName`, `scientificName` |
| `status` | Repeated values, currently VU / EN / CR | `conservation.category`; verified public summaries, formal dates unverified |
| `group` | Repeated taxonomy class values, currently Mammalia / Reptilia; displayed as Mammals / Reptiles | `taxonomy.class` and its cited taxonomic treatment |
| `habitat` | Repeated mountain / open-ocean / forest / grassland / reef-coast | Broad curated tags from each cited `descriptions.habitat` claim |
| `region` | Repeated asia / africa / ocean | Broad curated grouping of each cited `descriptions.distribution` claim |
| `sort` | narrative / name / name-desc / scientific | Documentary order, common name A–Z/Z–A, scientific name A–Z |

Selections within one group use OR; selected groups and name search use AND. No rank by headcount, decline percentage or conservation severity is offered. Counts describe records in this documentary only. The whole collection's options remain available even if a combination produces no result. Tiger belongs to both Forest and Grassland and appears once when both are selected.

Unknown URL facet/sort values are visibly explained and ignored while recognized selections remain active. An empty result provides the applied labels and Clear all filters. Missing photography or sound never excludes a species. Unmapped future records passed to the index builder receive explicit unclassified habitat/region facets; an unfamiliar taxonomy class remains an option rather than disappearing.

| Bornean orangutan | Forest | Asia; Borneo is grouped geographically under Asia | `wwf-orangutan`, Habitat / Distribution |
| Hawksbill sea turtle | Reef & coast | Ocean basins; retains tropical/subtropical scope in the record | `noaa-hawksbill`, Where They Live / About the Species |
| African forest elephant | Forest | West & Central Africa | `wwf-forest`, Habitat / Distribution |

These tags are navigation groupings, not exclusive habitat inventories, occurrence polygons, species co-occurrence, or evidence of absence elsewhere. Exact cited distribution text remains on each detail page. A reviewed change to the scientific description needs a corresponding review of `src/features/species/model.ts`. Related records use shared broad habitat/region/group tags and label their editorial relationship; no shared ecological encounter is implied.

## Components, motion, and page states

The explorer's form, pending state, and URL navigation are the small client boundary; complete cards, cited claims, image credits, and evidence registers render on the server. The scientific bundle is not imported into the client filter code. Apply navigates without forced scrolling, preserves the mounted input/button and keyboard focus, and announces the committed result count. Back/Forward synchronizes the fields from URL state. Pending requests retain usable prior records; the button announces Applying filters, and the result region is busy.

GSAP and `@gsap/react` load only when motion and media preferences allow. A scoped context applies a 240 ms photo opacity/8 px translation after selection, with short stagger and complete cleanup. Body text, headings, controls, estimates and citations never hide or animate. Live reduced-motion/lighter-media preferences revert the scope; failed motion loading leaves full HTML content. No ScrollTrigger, pinning, Lenis owner or autoplay is introduced on these routes.

The portrait module reserves original image proportions and fits the full source photograph. This preserves the tiger's tourism context and avoids cropping an animal to force identical cards. Captions include creator, license, source/credit notes, location/date gaps and rehabilitation context. A failed image shows a written description while keeping credits and evidence. The species segment has an error boundary with Next 16.4's `retry` prop, which re-fetches the segment; there is no root loading boundary that obscures the reading path when JavaScript is disabled.

## Scientific display and access limits

- Only `snow-india-spai` and `blue-enp-2018` are rendered as population measurements. Their geography, measurement period, edition, method, uncertainty/gap and source dates remain attached. The other four species show the documented estimate gap. No isolated estimates are joined into a historical chart.
- Conservation category provenance is a verified public summary, not an authorized formal assessment. All six formal assessment dates remain unknown. The record verification date is clearly distinguished; future authorized precise dates have a separate date field.
- Threats, habitat, distribution, ecological role, trend interpretation, conservation actions and outcomes retain source links and check dates. Each species has a consolidated source register with primary links and exact locations, plus taxonomy and evidence gaps.
- No recording of any selected species is cleared. The sound section retains its cited knowledge and explicit missing-recording state, with a link to the existing independent NPS habitat listening room. Humpback audio is never represented as blue whale audio.
- Metadata includes common/scientific names, concise descriptions, relative canonical paths, and Open Graph article descriptions. Filter URLs use noindex/follow to avoid indexing many subsets of the same collection. No public domain or deployment configuration is added.
